# 🏎️ F1 Insights

### Fórmula 1 com mais contexto — para aprender, acompanhar e se divertir.

O **F1 Insights** é um projeto independente criado por Miguel para aproximar mais pessoas da Fórmula 1. Reúne explicações em linguagem acessível, ferramentas interativas e informações da temporada em um só lugar.

> Estratégias, corridas e curiosidades da F1 — sem precisar ser especialista para aproveitar.

## ✨ O que você encontra

- **Guias de F1:** explicações sobre pneus, stints, pit windows, undercut, overcut, Safety Car e o modo de ultrapassagem.
- **Calendário da temporada:** corridas, datas e resultados, com atualização automática pelo feed de dados e cópia local de reserva.
- **Estratégias:** cartões interativos para aprender os conceitos que podem mudar uma corrida.
- **Simulador de estratégia:** explore decisões de pneus e condições de pista.
- **Simulador de corrida:** escolha piloto, circuito, pneus e ritmo; acompanhe voltas, posições e desgaste estimado.
- **Quiz:** perguntas sorteadas de um banco temático, com alternativas em ordem variável.
- **Sobre e contato:** conheça o autor e encontre os canais do projeto.

Os simuladores são experiências recreativas com modelos simplificados. Os tempos, posições e desgastes exibidos não são telemetria nem previsões de uma corrida real.

## 🧰 Tecnologias

- HTML
- CSS
- JavaScript puro
- [Vercel](https://vercel.com/) para hospedagem

O projeto não precisa de etapa de compilação nem de dependências para funcionar: os arquivos do site são servidos diretamente pelo navegador.

## ☁️ Publicar na Vercel

1. Envie os arquivos do site para um repositório no GitHub.
2. Na Vercel, escolha **Add New Project** e importe esse repositório.
3. Selecione a pasta que contém `index.html`, `app.js` e `styles.css` como diretório raiz do projeto.
4. Use a configuração **Other** (site estático), sem comando de build; defina `.` como diretório de saída, se solicitado.
5. Faça o deploy. A Vercel publicará os arquivos e fornecerá um endereço para o site.

Se o repositório tiver somente os arquivos deste site na raiz, use a própria raiz como diretório do projeto.

## 🗓️ Dados do calendário e créditos

O calendário consulta o feed público de [When’s the Race](https://whenstherace.com/), que utiliza dados do [F1DB](https://github.com/f1db/f1db) e horários do projeto [sportstimes/f1](https://github.com/sportstimes/f1). Os dados são usados sob **Creative Commons Attribution 4.0 (CC BY 4.0)** e os créditos também aparecem na página do calendário. Os nomes dos Grandes Prêmios exibidos em português foram localizados pelo F1 Insights.

O feed é independente e não oficial. Mudanças de calendário, disponibilidade e resultados dependem da atualização das fontes; consulte também a [programação oficial da Fórmula 1](https://www.formula1.com/en/racing).
